# 04 图纸取证方法与工具（中国施工图实战）

> 本文件解决一个核心问题：**中国施工图的 PDF 常常"读不了"**，必须换路子取证。

## 一、中国施工图 PDF 的三种"读不了"

| 类型 | 现象 | 判定方法 | 对策 |
|---|---|---|---|
| **A. 文字层缺失** | `get_text()` 返回空 | `extract_pdf.py` 报告 chars < 50 | 渲染为 PNG 后**图像识读** |
| **B. 文字层乱码** | 抽取出形如 `ᔰㆇᇼᓜ` 的字符 | 肉眼可见无意义 CJK 扩展区字符 | 同上（字体缺 ToUnicode 映射，不可恢复） |
| **C. 扫描件** | 整页为位图 | `page.get_images()` 有图、`get_drawings()` 极少 | 同上；若需文字须 OCR |

**结论：不要指望 PDF 文字提取。** 主力手段是 **① DWG 全量文字提取** + **② 图像识读**。

## 二、主力手段 1：DWG 全量文字提取（AutoCAD Core Console）

### 原理
用 AutoCAD 的 `accoreconsole.exe`（无界面）批量打开每个 DWG，运行 LISP 把全部
TEXT / MTEXT / DIMENSION / ATTRIB / INSERT / BLOCK 的文字与坐标导出为文本。
一次提取后，即可对**整个项目的所有 CAD 图纸做关键词检索**，效率远超逐张读图。

### 环境要求
- 已安装 AutoCAD（`accoreconsole.exe` 通常与 `acad.exe` 同目录）
- PowerShell 7（`pwsh`，用于 `ForEach-Object -Parallel`）

### 使用
```powershell
# 1) 修改 batch_dump2.ps1 顶部的 $acc / $dst / $root 三个变量
# 2) 运行（默认 5 个并发，accoreconsole 启动较慢，串行会非常久）
pwsh -File scripts/batch_dump2.ps1
```
输出：
- `_dwgtext/dwg001.txt ...`（GBK 编码）
- `_dwgtext/_manifest.csv`（key → 图纸相对路径，必留，检索时用于反查来源）

### 输出格式
```
DWGNAME|<图纸文件名>
TEXT|<图层>|<(x y z)>|<文字>
MTEXT|<图层>|<(x y z)>|<文字>
DIM|<图层>|<(x y z)>|<测量值>
ATTRIB|<属性名>|<值>
INSERT|<块名>|<图层>|<(x y z)>
===BLOCK|<块名>
```

### 坑与对策
| 坑 | 对策 |
|---|---|
| `(getvar "DWGTITLED")` 返回整数，`strcat` 报 `stringp 1` | 用 `(itoa ...)` |
| `SECURELOAD` 阻止加载 LISP | 脚本首行写 `SECURELOAD` + `0` |
| 多进程并发写同一输出文件 | 每个进程独立 slot 目录，各自输出 `cur.txt` |
| 中文路径 | 用参数传递（PowerShell 处理 Unicode 参数正常） |
| 编码 | 输出为系统 ANSI（中文为 GBK），Python 读时 `decode("gbk", errors="replace")` |
| 速度 | 单个 DWG 约 30～50s；**并行 5 个**，225 个 DWG 约 30 分钟 |

### 检索工具
```bash
python scripts/gw.py "关键词" [每条命中上限] [路径过滤串]
# 例：跨全项目找抗浮水位
python scripts/gw.py "抗浮" 6 ""
# 只在一个专业里找
python scripts/gw.py "消火栓" 6 "04-给排水"
# 找某单体的基准标高
python scripts/gw.py "±0.000(" 6 "01-建筑"
```

```bash
python scripts/near.py "<DWG名片段>" <x> <y> [窗口半宽]   # 按坐标窗口重建表格
python scripts/table.py "<DWG名片段>" x0 x1 y0 y1        # 重建表格区域
```

## 三、主力手段 2：图像识读

### 渲染
```bash
python scripts/render_all.py        # 全部唯一 PDF → PNG（zoom 2.0，A1 图约 3400×2400px）
python scripts/render_ext.py <pdf绝对路径>   # 渲染单个外部 PDF（项目资料、变更单、地勘附图等）
```
渲染脚本会自动：
- 跳过嵌套同名目录造成的重复
- 用 `md5(相对路径)[:12]` 命名 PNG，避免中文文件名问题
- 输出 `_manifest.json`（相对路径 → PNG 列表）

### 定位与放大
```bash
python scripts/findpng.py "路径片段" [上限]     # 路径片段 → PNG 绝对路径
python scripts/rendered.py "路径片段"           # 查看哪些已渲染
python scripts/crop.py "<路径片段>" x0 y0 x1 y1 <out.png> <zoom> [页码]
```
- `x0 y0 x1 y1` 是**页面比例 0～1**（左上、右上、左下、右下顺序为 x0 y0 x1 y1）
- zoom 取 4～6 可读表格与尺寸链；读印章文字、小号标注取 7～8
- 单边超 8192px 读取失败，需分块

### 识读策略（省 token）
1. 先整张读（把握构图与标题栏），再对关键表格/尺寸链局部放大复核
2. 优先读：图纸目录、设计说明、总平面图、平面图、剖面图、门窗表/材料表、大样图
3. 一套图里"说明类"图纸信息密度最高，优先读
4. 同一个单体的平/立/剖要连着读，才能发现标高与尺寸矛盾

## 四、专项取证技巧

### 1. 像素级比对（判定"图纸张冠李戴 / 重复使用"）
将两张同尺寸 PNG 逐像素比较，统计灰度差 > 40 的像素占比：
- 差异 < 1% → 实为同一张图（换了标题/图签）
- 差异 1%～5% → 大幅套用
- 差异 > 10% → 不同图纸

工具：`scripts/dupscan.py`、`scripts/pixdiff.py`
**这是客观、可复核的证据**，会审会上很难被反驳。

### 2. MD5 比对（判定"重复归档是否一致"）
同名文件在不同文件夹时，直接比对 MD5：一致说明是同一份，可明确"以哪一份为准"。

### 3. 地勘报告全文提取
```bash
python scripts/read_docx.py "<报告.docx>" "<输出txt>"
```
然后检索：抗浮水位、承载力特征值、场地类别、液化、基础选型建议、持力层、
基坑支护建议、勘探点标高。**这些是校核结构设计与基坑设计的基准。**

### 4. 坐标窗口重建表格
DWG 里的表格是散落的 TEXT，按 y 降序、x 升序排列即可还原成表：
```bash
python scripts/near.py "通用设计说明" -395000 -376000 -216000 -262000
```

## 五、常见"读不出来"的疑难与结论表述

| 疑难 | 正确处理 |
|---|---|
| CAD 与盖章 PDF 数值不一致 | **以盖章 PDF 为准**，差异列为问题要求书面确认；不能只凭 CAD 下判断 |
| 说明条文里的下划线空白 | 必须在**盖章 PDF** 上放大确认；CAD 常为未填模板或旧版 |
| 小号标注（6.010 之类）看不清 | 标注"需设计确认"或以原蓝图复核，不猜 |
| 图签项目名称两位字串重叠 | 直接写"项目名称栏重叠打印、不可读"——这本身就是问题 |
| 无文字层的扫描专篇 | 只做读图比对，无法逐条核对时明确说明边界 |

## 六、工具清单速查

> **使用前先配置路径**：`python scripts/common.py --init` 生成 `config.json`，修改 `drawing_root` 等项；
> 也可用环境变量覆盖（`DRAWING_REVIEW_ROOT`、`DRAWING_REVIEW_DWGTEXT` …）。

| 脚本 | 用途 |
|---|---|
| `common.py` | **统一路径与工程信息配置**（所有脚本的公共依赖） |
| `ledger.py` | 图纸台账与编号异常 |
| `extract_pdf.py` / `probe.py` / `summarise.py` | PDF 文字层检测 / 抽样 / 覆盖汇总 |
| `render_all.py` / `render_ext.py` | 批量 / 单个（图纸目录外）渲染 |
| `findpng.py` / `rendered.py` / `crop.py` | 定位、进度、高倍放大 |
| `dump.lsp` / `dump.scr` / `batch_dump2.ps1` | **DWG 全量文字提取（并行 5 路）** |
| `gw.py` / `near.py` / `table.py` / `subitems.py` | DWG 文字检索、坐标窗口与表格重建、子项概况提取 |
| `dump1.py` / `grepdwg.py` | 单文件导出 / 跨文件检索（GBK） |
| `dupscan.py` / `pixdiff.py` | MD5 重复归档、**像素级近似/套用检测（含批量报表）** |
| `read_docx.py` | docx 全文提取（地勘报告等） |
| `merge_findings.py` / `make03.py` / `make_docs.py` | 合并清单、生成交付物 |

> 依赖：`pymupdf`（PDF 渲染与文本）、`openpyxl`（Excel）、`python-docx`（Word）。
> 安装：`python -m pip install pymupdf openpyxl python-docx`
> DWG 提取额外需要：AutoCAD（含 `accoreconsole.exe`）与 PowerShell 7。
