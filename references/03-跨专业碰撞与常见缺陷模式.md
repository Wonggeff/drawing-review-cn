# 03 跨专业碰撞清单与常见缺陷模式库

> 本文件分两部分：**A. 跨专业必查对撞项**（每次都要做）；**B. 缺陷模式库**
> （从实际项目提炼的高频、易漏、且一旦漏掉后果严重的问题模式，附检索/核查手法）。

---

# A. 跨专业必查对撞项

| # | 对撞内容 | 涉及专业 | 核查手法 | 常见问题 |
|---|---|---|---|---|
| A1 | **各单体 ±0.000 绝对标高一览表** | 总图·建筑·结构·给排水·景观·装修 | `gw.py "±0.000("`、`gw.py "绝对标高"`、`gw.py "相当于绝对标高"` 全项目检索并列表 | 一览表缺失；各单体基准不同（坡地项目常见 5 种以上）；装修/景观说明照抄某一栋的基准 |
| A2 | **建筑面层厚度 — 结构标高对照** | 建筑·结构 | 比对建施楼面标高与结构"板施工及标高示意图" | 无对照表；结构层楼面标高**高于**建筑完成面（面层为负） |
| A3 | 防火分区编号与面积 | 建筑·电气·暖通·给排水 | 对比防火设计说明、建筑单图图名、电气防火分区图、排烟计算 | 三套编号并存；分区面积与子项概况不一致；栋数与清单不符 |
| A4 | 消防水源与自动灭火系统 | 建筑·给排水·电气 | 建筑说明 4.x 与七、设备用房 ↔ 给排水系统图/材料表 ↔ 电气联动逻辑 | 建筑称"设自动喷水灭火系统"而给排水无喷淋；称"不设消防水池/泵房/水箱"而系统为市政直供，水量水压无依据 |
| A5 | 抗浮设防水位 | 结构·建筑·勘察 | 结构说明 ↔ 地勘 3.x 抗浮评价 ↔ 建筑防水专篇的 H≥0m/H<0m 判定 | 结构取值与地勘建议值不一致；"无需抗浮"与"设止水帷幕"逻辑不自洽 |
| A6 | 结构预留洞/套管/预埋件 | 结构·给排水·电气·暖通·智能化·幕墙 | 结构图 vs 各机电平面 | 缺失；后凿结构 |
| A7 | 设备用房 | 建筑·结构·电气·暖通·给排水·智能化 | 位置、面积、防火分隔、荷载、通风散热、排水、供电 | 房间在不同专业图纸上位置/面积不一致；机房空调责任真空 |
| A8 | 卫生间降板与防水 | 建筑·结构·给排水·装修 | 建筑完成面标高 ↔ 结构降板标高 ↔ 给排水大样 ↔ 装修铺装 | 给排水大样标高与建筑差 0.8m；无防水翻边；挡水门槛高度三处不一致 |
| A9 | 设计范围与送审范围 | 全部 | 设计总说明"三、设计范围" ↔ 送审盖章图纸集实际分册 | 说明称装修/亮化/幕墙/演艺/电梯不在范围内，图纸集却包含；或反之缺失 |
| A10 | 面积与指标闭合 | 总图·建筑·各专业 | 逐行验证"建筑面积 = 计容 + 不计容"；各单体之和 = 总建筑面积；基底面积之和 = 指标表 | 子项概况表某行算不平；各表之和不等于总数；指标表与一览表差上百平方米 |
| A11 | 层数/高度/使用性质 | 总图·建筑·结构·消防·节能 | 总平面图一览表 ↔ 子项概况表 ↔ 各单体建施图 ↔ 结构概况表 | 同一单体 1F/2F 并存；"建筑高度"一处填檐口、一处填屋脊；使用性质不一致 |
| A12 | 单体编号与名称 | 全部 | 文件名 ↔ 图签子项名称 ↔ 图内引用 ↔ 设计总说明 | 编号与名称互相颠倒；错字（忠/中、香/像）；一物两名 |
| A13 | 图纸集组织 | 全部 | 台账 + MD5 比对 + 像素比对 | 整目录重复归档；同名文件版本不明；**说明类图纸张冠李戴** |
| A14 | 版本与签章 | 全部 | CAD 版 vs 盖章版数值比对；变更单日期 vs 审图章日期；注册师印章有效期 | 盖章图为旧版；变更未审图；印章有效期早于审图章日期 |
| A15 | 景观堆土/覆土与结构荷载 | 景观·结构·绿化 | 景观竖向/种植说明 ↔ 结构覆土限值表 | 结构未给限值；600mm 档无结构取值；乔木土球超覆土 |
| A16 | 室外管线综合与避让 | 给排水·电气·智能化·景观·海绵·基坑 | 管线综合平面 + 与基础/止水帷幕/既有建筑的剖面 | 无综合图；与文物本体/既有建筑净距未控制 |
| A17 | 装修点位 ↔ 机电末端 | 装修·电气·给排水·暖通·智能化·消防 | 装修天花图 ↔ 各机电平面点位 | 天花图未综合风口/喷淋/烟感/广播/检修口 |
| A18 | 亮化与建筑电气界面 | 亮化·电气·景观 | 图号体系、配电箱编号、供电来源、控制系统 | 两套供电方案冲突；配电箱缺号重号；目录与图签两套图号 |
| A19 | 与一期/既有建筑的衔接 | 建筑·结构·给排水·景观·消防 | 总平面图 ↔ 一期图纸；防火墙、脱开、管网接驳 | 完全未交代；防火间距论证遗漏某栋并自相矛盾 |
| A20 | 无障碍通行连续性 | 总图·建筑·景观·装修 | 无障碍车位 → 场地路径 → 建筑入口 → 楼层 → 卫生间 全链条 | 链条断开（有大样无路径、有坡道无扶手、入口仅台阶） |

# B. 缺陷模式库（高频、易漏、后果重）

## B1 标高类
| 模式 | 检索/核查手法 | 典型表现 |
|---|---|---|
| 基准标高错配 | `gw.py "相当于绝对标高"` 对照各专业 | 装修说明照抄 42.15m，而本单体基准 38.30m（差 3.85m） |
| 结构高于建筑完成面 | 比对结构板标高表与建施楼面标高 | 结构 7.520 vs 建筑外廊完成面 7.500 |
| 平立剖标高不一致 | 同单体的平/立/剖三向对比 | 檐口在一处 7.250、另一处 7.850（差 600mm） |
| 大样图出现第二套标高 | 检索远超场地高程范围的数值 | 水景详图标 21.200，而场地为 37.80~42.15 |
| 场景混用相对/绝对 | 检索 `(3x.xx)` 形式的绝对标高标注 | 同一张图 `-0.100` 标为 (37.90) 与 (38.10) |

## B2 图纸集组织类
| 模式 | 检索/核查手法 | 典型表现 |
|---|---|---|
| 说明类图纸张冠李戴 | **像素级比对**；核对图签"子项名称" | 某单体的 DI-01～05 五张全部属于其他单体 |
| 原始建筑平面图 = 平面图副本 | 像素比对；看有无"拆除/新增/封堵"标注 | 装修"原始建筑平面图"与"平面图"逐间一致 |
| 图号体系并行 | 对比目录图号与图签图号 | 目录 DS-01~DS-27，图签 DS-04~09 且缺 DS-06 |
| 整目录重复归档 | 台账 + MD5 | 内层同名子目录重复收录 421 个 PDF |
| 图名错字/叠号 | 台账文件名正则 | "4-4面剖面图"、"072、071、…" |
| 张数/幅面/页码空白 | 读图纸目录 | 张数列 100% 空白 |
| 目录与实到不符 | 台账张数 vs 目录条目 | 目录 17 项、实到 19 张、缺"大样图（三）" |

## B3 跨专业对撞类
| 模式 | 核查手法 | 典型表现 |
|---|---|---|
| 说明声明的系统实际没做 | 建筑说明 ↔ 对应专业系统图/材料表 | 称设自动喷水灭火系统，给排水仅"轻便消防水龙" |
| 专业间互相"甩锅" | 找"由××公司二次设计""详见××图纸" | 机房精密空调"由专业设计完成"、灯具定位"详见电气图纸" |
| 一物多值 | 全项目检索同一参数 | 地下室防水门槛 120/150/200；同一水位对应两个池底标高 |
| 计算书主体信息错误 | 读计算书封面 | 所处城市"北京"；建设单位填成软件供应商 |

## B4 规范与签章类
| 模式 | 核查手法 | 典型表现 |
|---|---|---|
| 规范编号错漏 | 逐条核对设计依据表 | 《木结构设计标准》GB5005-2017（应为 GB 50005-2017） |
| 规范年份/名称过时 | 核对现行版本 | GB 50222-2022（应为 2017）；"规范"应为"标准"；引用已废止标准 |
| 引用不适用规范 | 核对项目类型 | 文旅公共建筑引用《住宅设计规范》 |
| 规范名称与编号不符 | 逐条配对 | "GB 50136-2021"配《建筑环境通用规范》（应为 GB 55016-2021） |
| 印章有效期早于审图章 | 读图签印章 | 注册师章"至 2025 年 6 月"，审图章 2025.07.23 |
| 一人多岗 | 读设计签字栏 | 同一人任项目负责/审核/审定 |

## B5 危大与安全类（必须单列、单独立项）
- 基坑：安全等级与 γ₀ 不自洽、计算未计地下水、稳定系数无余量、嵌固深度差 2m 以上、
  止水帷幕未进入地勘指定目标层、**另一单体基坑设计完全缺失**、无监测点布置图
- 楼梯：同一梯段级高混用、踏步宽 < 280mm、梯段净宽 < 1.20m（公共建筑）
- 栏杆/美人靠：临空防护 < 1.05m、无竖杆净距、无预埋件与抗水平推力
- 脊饰/高空构件：无重量、无抗风抗震固定要求（坠物风险）
- 玻璃栈道/玻璃栏杆：无支承结构、无承载等级、无节点大样
- 木结构体系：无上部结构施工图（主体结构无设计依据）

## B6 深度不足类（会导致无法施工或返工）
- 屋面构造层次不完整（缺找坡/保温/苫背/挂瓦条/顺水条/瓦件搭接）
- 地下室防水节点缺失（底板/外墙/施工缝/后浇带/桩头/穿墙管根）
- 装配式/幕墙/门窗：仅"由厂家深化"，未给荷载、埋件、预留条件
- 二次设计（雕刻、楹联、脊饰、演艺、标识、展陈）无责任方与时间节点
- 桩表、承台表、独立基础表空缺或与图不符
- 面积明细不闭合（房间面积之和 ≠ 总面积）

# C. 会审问题优先级判定

| 优先级 | 判定标准 | 处理 |
|---|---|---|
| **一级** | 涉及结构安全、消防安全、文物安全、危大工程；或导致无法确定施工依据的版本冲突 | 会审会上必须闭环；未闭合前相关部位暂停施工 |
| **二级** | 影响使用功能、造价、工期；需要在采购/加工前澄清 | 开工前闭环（如门窗表、材料表须在招标前澄清） |
| **三级** | 图纸质量、报批报审、指标不闭合、目录图号 | 随设计修订一并解决 |

**"现场暂停项"必须写清楚**：哪些部位在取得设计书面确认前不得施工，
避免以"边干边改"方式留下无法追溯的质量与结算争议。
